How do I create a token? (one-time setup)
  1. Open github.com/settings/personal-access-tokens/new.
  2. Name it Portfolio Admin and choose an expiry.
  3. Repository access: Only select repositories → portfolio.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate the token, copy it, and paste it above.

The token is stored in this browser only. Revoke it any time on GitHub.
